# ReactJS Projects for Beginners

All projects were created for the free course on the [Archakov Blog](https://www.youtube.com/c/ArchakovBlog) YouTube channel.

Each project is stored in a separate branch.

## Counter
![1660249082356](https://user-images.githubusercontent.com/12086860/184235207-2d20299a-0b9a-40e6-acf7-be582f6ecbfe.png)

**🌿 Branch**: `counter`

**👀 What will we learn?**
1. What state is
2. How to use the `useState` hook
3. How to call a function when a button is clicked

## Guest List (Users)
![1660249789449](https://user-images.githubusercontent.com/12086860/184236601-2c8d94bf-105c-4b48-982c-65a6ed4f8c51.png)

**🌿 Branch**: `users`

**👀 What will we learn?**
1. How to use the `useEffect` hook
2. Sending a request to a backend with `fetch` and rendering the returned data
3. Creating a skeleton loader with the `react-content-loader` library
4. Searching for users
5. Rendering a list of users
6. Using the spread operator
7. Adding and removing users from an invitation list
8. Displaying content-loading status
